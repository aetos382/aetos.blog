# 記事に画像を追加する

引数: `$ARGUMENTS`

- 既存の記事:

!`ls src/content/blog`

## 手順

ツール呼び出しは、下の node コマンド 1 回だけで済ませる。画像を Read したり、確認のためにコマンドを実行したりしない。

1. 引数を解釈する。
   - 1 つ目を slug、2 つ目を名前とする。名前は拡張子なしの小文字の kebab-case にする（拡張子は入力の形式から決まる）。
   - `--max-width <px>` があれば、スクリプトにそのまま渡す。
   - 残りの引数があれば、それを入力画像のパスとする。
2. 入力画像を決める。
   - パスが指定されていれば、それを使う。
   - パスがなければ、このメッセージに添付された画像を使う。添付された画像の保存先のパスは、メッセージ中の `[Image: source: <パス>]` にある。
   - 添付が 2 つ以上ある場合、またはパスも添付もない場合は、実行せずにその旨を報告して終わる。
3. 次のコマンドを実行する。

   ```sh
   node .claude/skills/add-image/optimize-image.mjs '<入力画像のパス>' '<slug>' '<名前>' [--max-width <px>]
   ```

4. 結果を報告する。
   - 成功した場合: 出力先のパス、縮小前後の寸法とファイル サイズ、本文に貼る `macro` の行（代替テキストはユーザーが入れる）を報告する。
   - 失敗した場合: エラー メッセージをそのまま伝える。同名のファイルがある、記事がない、非対応の形式である、などの場合は、引数を変えて再実行するようユーザーに伝える。自分で名前を変えて再実行しない。

## 補足

- 本文の画像は Astro の最適化を通らないため、このスキルで事前に最適化する。既定の最大幅は、本文の幅（720px）の 2 倍の 1440px。拡大はしない。
- 対応形式は JPEG・PNG・WebP・AVIF で、形式は変えない。PNG は色数を減らして圧縮する（スクリーンショット向け）。
- EXIF などのメタデータ（位置情報を含む）は除く。回転の情報は、除く前に画素へ反映する。
- 記事の `images/.gitkeep` は、画像を置いた時点で不要になるので削除する。
